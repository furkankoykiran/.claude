# Codex gateway evidence

Gateway protocol diagnostics, regression details and the historical Penpot acceptance baseline now live in the [Codex gateway repository](../gateways/claude-codex-gateway/docs/codex-wave1-evidence.md). Its [contract](../gateways/claude-codex-gateway/docs/contract.md) describes provider behavior; its [verification](../gateways/claude-codex-gateway/docs/verification.md) distinguishes fresh checks from historical evidence.

The toolkit owns provider selection, configuration, capability detection, process lifecycle and pinned submodule versions. See the [provider capability matrix](provider-capability-matrix.md) and [gateway family evidence](gateway-family/EVIDENCE.md) for integration status.
